# AI Internship Eligibility Checker

## Task ID
AI-SS-007

## Project Description

The AI Internship Eligibility Checker is a Python-based system that evaluates
student eligibility for internship programs.

The project uses:

- Rule-Based Logic
- Python
- Pandas
- NumPy
- Scikit-learn
- Decision Tree Classification

## Features

- Student profile evaluation
- CGPA validation
- Year of study validation
- Domain validation
- Backlog validation
- Skills validation
- Decision Tree prediction
- Eligibility probability
- Internship program recommendations
- Detailed eligibility report

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
